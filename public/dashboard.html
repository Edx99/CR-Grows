🧭 Ayuda y plantillas reutilizables

Aquí tienes cuatro modelos listos para adaptar. Puedes abrirlos directamente o crear una versión personalizada con tus propias actividades y descargarla como un archivo HTML nuevo.

Plantilla HIIT interactiva

Ideal para rutinas rápidas con ejercicios que cambian automáticamente. Perfecta para entrenamientos de agilidad o fuerza.

const exerciseList = [
  "Burpee",
  "Saltos",
  "Plancha"
];

Plantilla de frases reproducibles

Útil para rutinas de afirmaciones, práctica verbal o sesiones de repetición secuencial.

const exercisePool = [
  "Soy fuerte",
  "Soy disciplinado"
];

Plantilla de control financiero

Ideal para registrar metas financieras, hábitos de ahorro y seguimiento semanal de gastos o ingresos.

Plantilla de frases audible

Perfecta para repetir afirmaciones o mensajes de impulso con un enfoque más sonoro y emocional.

Crear una rutina personalizada

Escribe las actividades o frases que quieras usar y el sistema generará un archivo HTML nuevo listo para descargar.
